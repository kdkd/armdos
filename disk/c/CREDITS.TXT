                         ARM-DOS 1.0  -  CREDITS
                         =======================

  Copyright (C) 2026 Kevin Day, with lots of help from Europa.

  ARM-DOS is an imagined 1988 PC with an ARM processor, and most of what
  runs on it was written for it: the BIOS, the DOS kernel, COMMAND.COM,
  the emulator and the web page around it, and dozens of programs. Where
  a notice says "Europa Micro Systems", that is the machine's make-believe
  manufacturer, and the work is part of ARM-DOS.

  A great deal more came from other people who were kind enough to share
  their work. This file lists every such piece: what it is, who made it,
  the licence it is used under, and where it came from. Many programs also
  keep their own licence file next to them on this disk. Where a licence
  asks for the source code to be offered, the ARM-DOS project offers it.

  Contents
    1. The system            5. Sound and music
    2. Programming           6. The x86 gallery under ELBOW
    3. Games                 7. Demos, the CD-ROM and ARM-DOS Online
    4. GEM                   8. Fonts, data and references

1. THE SYSTEM
==========================================================================

MS-DOS 4.00 (the model for ARM-DOS)
  (C) IBM and Microsoft Corporation. Released as source code by Microsoft
  under the MIT License (github.com/microsoft/MS-DOS, v4.0).
  ARM-DOS's kernel (IO.SYS, ARMDOS.SYS), HIMEM.SYS and COMMAND.COM are new
  C and ARM code. Their behaviour and their messages follow that source,
  so they include Portions (C) Microsoft Corp., MIT License.

DOS 4 commands carried over from Microsoft's source
  Portions (C) Microsoft Corp., MIT License.
  Compiled for the ARM from Microsoft's own C source:
    FC, MEM, ATTRIB, FDISK, JOIN, SUBST (and their shared helper library)
  Assembled from Microsoft's own source:
    KEYBOARD.SYS (plus a Dvorak layout added for ARM-DOS), COUNTRY.SYS
  Re-created in C from Microsoft's assembly source, step by step:
    ANSI.SYS, CHKDSK, COMP, DEBUG (now for ARM code), DISKCOMP, DISKCOPY,
    DISPLAY.SYS, EDLIN, FIND, FORMAT, KEYB, LABEL, MODE, MORE, NLSFUNC,
    PRINT, REPLACE, SORT, SYS, TREE, XCOPY

The DOS 4.00 Shell (DOSSHELL)
  New code for ARM-DOS, written from the real Shell's screens. The Shell's
  source is not part of Microsoft's release; none of its code is used.

The C runtime inside the programs
  newlib (Red Hat and many contributors), BSD-style licences.
  libgcc (Free Software Foundation), GNU GPL with the GCC Runtime Library
  Exception.
  Every program built with the ARM-DOS SDK contains parts of both, and
  C:\TC\LIB\LIBC.A and the headers in C:\TC\INCLUDE come from them.

Turbo Vision (used by EDIT, ARM Turbo C and ARM QuickBASIC)
  Borland International made the original source public; the modern
  port is by magiblot (github.com/magiblot/tvision), MIT License plus
  Borland's original disclaimer. The ARM-DOS platform layer is new.

Original ARM-DOS programs (no third-party code)
  AC, ARMINFO, ARMCDEX, ARMCD.SYS, BANNER, CDPLAY, CRASH, DEFRAG, DEMO,
  DOCTOR, SAY, ELBOW, FILE, HERCULES, JOYTEST, MOUSE, ONLINE, PAINT,
  PLAYMIDI, POPUP, SBMIX, SBTEST, TERM, TURBO, UNZIP, and The ARM Pit BBS
  with its door games. Their looks are homages to programs of the era;
  none of those programs' code or text was used.

8. FONTS, DATA AND REFERENCES
==========================================================================

The screen fonts
  The Ultimate Oldschool PC Font Pack (C) 2016-2020 VileR,
  https://int10h.org/oldschool-pc-fonts/ , licensed under CC BY-SA 4.0
  (https://creativecommons.org/licenses/by-sa/4.0/). The VGA 8x16, CGA
  8x8 and MDA 9x14 character ROMs were converted from its IBM fonts with
  the glyphs unchanged. The code page fonts in C:\DOS\EGA.CPI come from
  the same pack's IBM fonts and their "Plus" variants, also CC BY-SA 4.0.

Dr. ARMitso's voice (DOCTOR, SAY)
  The letter-to-sound rules follow US Naval Research Laboratory report
  NRL-7948 by Elovitz, Johnson, McHugh and Shore (1976), a US Government
  work in the public domain. The doctor's manners were checked against
  Ralph Caraveo's MIT-licensed "Dr. Sbaitso: Reborn"; none of its data
  was used.

Checked against
  The genuine MS-DOS 4.00 programs, run in DOSBox-X, were the yardstick
  for how ARM-DOS should behave. Debian's game-data-packager helped
  confirm that the shareware game files are the original releases, and
  many of the older archives were found through the Internet Archive.
