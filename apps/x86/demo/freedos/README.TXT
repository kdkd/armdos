FreeDOS programs, run on the ARM PC by ELBOW
============================================

  TREE.COM     3.7.2a  Dave Dunfield, Kenneth J. Davis     GNU GPL v2
  FIND.COM     3.0b    Jim Hall                            GNU GPL v2
  MORE.EXE     4.3a    Jim Hall (FreeDOS)                  GNU GPL v2
  CHOICE.EXE   4.4a    Jim Hall (FreeDOS)                  GNU GPL v2

These are the unmodified binaries from the FreeDOS 1.3 base repository
(ibiblio.org/pub/micro/pc-stuff/freedos/files/repositories/1.3/base).  The
complete packages, with the program sources (SOURCE\...\SOURCES.ZIP), the
licence texts and documentation, are in SOURCE\ next to them - the GPL's
"accompanied by the complete corresponding source code".

Try:    ELBOW TREE \
        ELBOW FIND /I /N "elbow" ..\README.TXT
        ELBOW CHOICE /C:YN Is this an ARM
