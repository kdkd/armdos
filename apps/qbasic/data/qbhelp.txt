.topic Survival Guide
  ARM QuickBASIC Survival Guide

  Using the menus:  press Alt to activate the menu bar, then the highlighted
  letter of a menu (or Left/Right and Enter). Alt+letter opens a menu at
  once. Esc closes a menu. You can also click with the mouse.

  Getting help:     press Shift+F1 for help on using help, or move the
                    cursor to a BASIC keyword and press F1.
  Running:          press F5 to run the program in the program window.
  Stopping:         press Ctrl+Break to stop a running program.
  Exiting:          press Alt, F, X (File menu, Exit).

  Where to go next:
    {Contents}            all the help, by subject
    {Index}               an alphabetical list of every help topic
    {Keywords by Task}    BASIC keywords grouped by what they do
    {Using Help}          how to move around in help
    {Keyboard}            the editing keys
    {Samples}             example programs to load and run
    {Differences}         how ARM QuickBASIC differs from other BASICs

.topic Using Help
  Using Help

  Shift+F1      opens this topic.
  F1            shows help on the BASIC keyword at the cursor, or on the
                menu command or dialog box you are in.
  Tab           moves to the next cross reference (a highlighted word).
  Shift+Tab     moves to the previous cross reference.
  Enter         shows the topic of the selected cross reference; a double
                click on a cross reference does the same.
  Alt+F1        goes back to the topic you saw before (up to 16 topics).
  Shift+F1      in the help window: shows the {Index}.
  F6            switches between the help window and the other windows.
  Esc           closes the help window.

  The help window opens at the top of the screen; use the arrow keys, PgUp
  and PgDn or the scroll bars to read the whole topic. Examples can be
  copied into your program: see {Edit Menu}.

  See also: {Contents}  {Index}  {Help Menu}

.topic Menus,Menu Bar
  The Menu Bar

  The menu bar is at the top of the screen:

    File  Edit  View  Search  Run  Debug  Options               Help

  Press Alt (and release it) to activate the menu bar, then press the
  highlighted letter of a menu, or use Left, Right and Enter. Alt+letter
  opens a menu directly (Alt+F for File). In a menu, press the highlighted
  letter of a command or move with Up / Down and press Enter. Esc closes
  the menu. With the mouse, click a menu, then a command.

  Many commands have shortcut keys, shown next to them in the menu. A
  command followed by "..." opens a dialog box. Press F1 on a command to
  get help on it.

  The status line at the bottom of the screen shows the most useful keys
  and the cursor position (line:column):

    <Shift+F1=Help> <F6=Window> <F2=Subs> <F5=Run> <F8=Step>

  {File Menu}    {Edit Menu}    {View Menu}     {Search Menu}
  {Run Menu}     {Debug Menu}   {Options Menu}  {Help Menu}

.topic File Menu
  File Menu

  New          Removes the program in memory and starts a new, untitled
               one. You are asked whether to save any changes.
  Open...      Loads a program (.BAS file) from disk. Choose a file in the
               list, or type a name; directories change with a double
               click. You are asked whether to save the current program.
  Save         Saves the program under its name (Save As... if untitled).
  Save As...   Saves the program under a new name.
  Print...     Prints the program, or the selected text, on the printer.
  Exit         Leaves ARM QuickBASIC and returns to ARM-DOS. You are asked
               whether to save any changes.

  Programs are saved as plain text files; any text editor can read them.
  The name of the program is shown in the title of the program window
  ("Untitled" for a new program).

  See also: {Menus}  {Samples}

.topic Run Menu
  Run Menu

  Start      Shift+F5  Clears all variables and runs the program from the
                       beginning.
  Restart              Clears all variables and prepares to step through
                       the program: the first statement is highlighted;
                       press F8 to execute it.
  Continue   F5        Continues the program after a break, a breakpoint
                       or a step. If the program has not been started (or
                       it was edited), F5 starts it from the beginning.

  While the program runs you see the {Output Screen}. When it ends,
  "Press any key to continue" appears at the bottom; press a key to return
  to the editor. Ctrl+Break stops a running program: the next statement is
  highlighted, and F5 continues it.

  See also: {Debug Menu}  {Debugging}  {Run-Time Errors}

.topic Debug Menu
  Debug Menu

  Step                  F8   Executes the next statement. The statement
                             that will be executed next is highlighted.
  Procedure Step        F10  Like Step, but executes a whole SUB or
                             FUNCTION call as one step.
  Trace On                   Not available in ARM QuickBASIC.
  Toggle Breakpoint     F9   Sets or removes a breakpoint on the line at
                             the cursor. The line turns red; the program
                             stops before executing it.
  Clear All Breakpoints      Removes every breakpoint.
  Set Next Statement         Makes the statement at the cursor the next
                             one to be executed (F5 or F8 continues there).

  See also: {Debugging}  {Run Menu}  {Immediate Window}

.topic Debugging
  Debugging a Program

  1. Set a breakpoint (F9) on a line, or press F8 to start stepping.
  2. Run the program (F5). It stops before the breakpoint's line; that
     line is highlighted.
  3. Look at variables in the {Immediate Window}: type PRINT X and press
     Enter. You can also change them there: X = 10.
  4. Step with F8 (into SUBs) or F10 (over SUB and FUNCTION calls), or
     continue with F5. Press F4 to look at the {Output Screen}.

  Ctrl+Break stops a running program at any time. After a run-time error
  the cursor is at the statement that failed; correct it and press F5 to
  run the program again.

  See also: {Debug Menu}  {Run Menu}  {STOP}  {Run-Time Errors}

.topic Immediate Window
  The Immediate Window

  The Immediate window is below the program window. Press F6 to move to it
  (and F6 again to go back). Type a BASIC statement and press Enter: it is
  executed at once, and uses the variables of your program:

.ex
PRINT 2 + 2
X = 5
PRINT X * 3, SQR(X)
CALL MySub
.endex

  If the statement prints anything, the {Output Screen} appears with
  "Press any key to continue". The lines you type stay in the window: move
  the cursor to one and press Enter to execute it again.

  Use it to try out statements, to test a {SUB} or {FUNCTION}, and to look
  at or change variables while a program is stopped (see {Debugging}).

.topic Output Screen
  The Output Screen

  Your program does not print into the program window: it has a screen of
  its own, the output screen. While the program runs you see the output
  screen; when it ends, "Press any key to continue" appears at the bottom
  and a key returns you to the editor.

  Press F4 (View menu, Output Screen) to look at the output screen again at
  any time; press any key to return.

  See also: {SCREEN}  {CLS}  {Run Menu}

.topic Differences
  How ARM QuickBASIC Differs

  ARM QuickBASIC runs programs with Bywater BASIC 3.40 (GNU General Public
  License, version 2) behind its own editor and debugger. Most programs
  run unchanged, but note:

  - All variables are global: a SUB or FUNCTION sees the variables of the
    main program. Parameters are passed by value, so a SUB cannot change
    its arguments; use a FUNCTION or a global variable instead.
  - DECLARE, SHARED, COMMON and STATIC are accepted and ignored.
  - There is no TYPE ... END TYPE, no graphics GET and PUT, no VIEW or
    WINDOW, and no event trapping (ON KEY, ON TIMER).
  - PLAY and SOUND wait until the music is done (no background music).
  - Numbers are double precision; PRINT shows 6 significant digits.
  - Errors are reported when the program runs, not when you type a line:
    the editor does not check the syntax as you type.
  - The program is one text: SUBs and FUNCTIONs are not shown in separate
    windows (use F2 to find them). Files are plain text; there is no
    binary .BAS format.
  - SCREEN supports the modes 0, 1, 2 and 13 only.

  See also: {SUB}  {Variables}  {SCREEN}

.topic Run-Time Errors,Errors,Error Messages
  Run-Time Errors

  When a statement fails, the program stops and a dialog box shows the
  message; the cursor moves to the statement. Correct it and press F5.

  Syntax error             The statement is not valid BASIC: a misspelled
                           keyword, a missing parenthesis or comma.
  Division by zero         An expression divides by zero (/, \ or MOD).
  Overflow                 A result is too large for its data type.
  Subscript out of range   An array index is outside the bounds of DIM.
  Illegal function call    An argument is not allowed, e.g. SQR(-1) or
                           a SCREEN mode that does not exist.
  Type mismatch            A string where a number is needed, or the
                           other way around (A$ = 5).
  Out of DATA              READ has no more DATA items to read.
  RETURN without GOSUB     RETURN was reached without a GOSUB.
  NEXT without FOR         A NEXT has no FOR, or a FOR has no NEXT
  FOR without NEXT         (also: DO/LOOP, WHILE/WEND, IF/END IF).
  Undefined line           GOTO or GOSUB names a missing line label.
  Out of memory            The program or its arrays are too large.
  File not found           OPEN, KILL, NAME ... names a missing file.
  Bad file number          The file number was not opened with OPEN.
  Input past end of file   INPUT # read past the end; test {EOF} first.

  See also: {ON ERROR}  {Debugging}

.topic Variables,Data Types,Variable Names
  Variables and Data Types

  A variable name starts with a letter and may contain letters, digits
  and periods (up to 40 characters). A suffix gives the data type:

    %   integer              A% = 5
    &   long integer         Big& = 100000
    !   single precision     Speed! = 1.5
    #   double precision     Pi# = 3.14159265358979
    $   string               Name$ = "Europa"

  A name without a suffix is single precision unless a {DEFINT} statement
  says otherwise. Upper and lower case are the same (Score = SCORE).

  ARM QuickBASIC calculates in double precision; PRINT shows numbers with
  6 significant digits (use {PRINT USING} or {STR$} for other formats).
  Strings can hold any characters, up to 32767 of them.

  Numbers can be written in decimal (12.5, 1E6), hexadecimal (&HFF) or
  octal (&O17).

  See also: {DIM}  {CONST}  {Operators}  {Differences}

.topic Operators,MOD,AND,OR,NOT,XOR,Expressions
  Operators

  Arithmetic   ^ power      * multiply     / divide     + add   - subtract
               \ integer division (7 \ 2 = 3)
               MOD remainder (7 MOD 2 = 1)
  Relational   =  <>  <  >  <=  >=   (true = -1, false = 0)
  Logical      NOT  AND  OR  XOR     (bitwise on integers)
  Strings      + joins strings ("AB" + "C" = "ABC"); relational operators
               compare them alphabetically

  Precedence, highest first: ^, - (negation), * /, \, MOD, + -,
  relational, NOT, AND, OR, XOR. Use parentheses to change the order.

  Syntax
    result = number1 MOD number2
    result = [NOT] expression1 AND | OR | XOR expression2

  MOD rounds both numbers to integers and returns the remainder of the
  division. AND, OR, XOR and NOT work bit by bit: IF A > 0 AND B > 0 is
  true when both conditions are true.

.ex
PRINT 17 MOD 5, 17 \ 5, 17 / 5
IF X >= 1 AND X <= 10 THEN PRINT "in range"
PRINT 12 AND 10, 12 OR 10, 12 XOR 10, NOT 0
.endex

  See also: {Variables}  {IF}

.topic ABS
  ABS - a math function that returns the absolute value of a number

  ABS(numeric-expression)

  The absolute value is the number without its sign: ABS(-5) and ABS(5)
  are both 5.

.ex
PRINT ABS(-3.5), ABS(2)
.endex

  See also: {SGN}  {INT}

.topic ASC
  ASC - a string function that returns the ASCII code of a character

  ASC(stringexpression)

  Returns the code (0-255) of the first character of the string. The
  string must not be empty. {CHR$} does the opposite.

.ex
PRINT ASC("A")          ' 65
K$ = INKEY$: IF K$ <> "" THEN PRINT ASC(K$)
.endex

  See also: {CHR$}  {VAL}

.topic ATN
  ATN - a math function that returns the arctangent of a number

  ATN(numeric-expression)

  The result is an angle in radians, between -PI/2 and PI/2. To convert
  radians to degrees, multiply by 180 / PI.

.ex
PI = 4 * ATN(1)
PRINT PI
.endex

  See also: {TAN}  {SIN}  {COS}

.topic BEEP
  BEEP - a statement that sounds the speaker

  BEEP

  Sounds a short tone. PRINT CHR$(7) does the same.

.ex
INPUT "Guess"; G
IF G <> 7 THEN BEEP: PRINT "Wrong!"
.endex

  See also: {SOUND}  {PLAY}

.topic CHR$
  CHR$ - a string function that returns the character with an ASCII code

  CHR$(code%)

  code% is a number from 0 to 255. Useful for characters you cannot type,
  such as quotation marks (34) or the box-drawing characters (179-218).

.ex
PRINT CHR$(65); CHR$(66); CHR$(67)     ' ABC
PRINT CHR$(34); "quoted"; CHR$(34)
FOR I = 176 TO 178: PRINT STRING$(10, I): NEXT
.endex

  See also: {ASC}  {STRING$}

.topic CINT,CLNG
  CINT - a conversion function that rounds a number to an integer

  CINT(numeric-expression)
  CLNG(numeric-expression)

  CINT rounds to the nearest integer (-32768 to 32767); CLNG rounds to a
  long integer. Numbers ending in .5 are rounded to the even integer.

.ex
PRINT CINT(2.5), CINT(3.5), CINT(-2.7)     ' 2  4 -3
.endex

  See also: {INT}  {FIX}

.topic CIRCLE
  CIRCLE - a graphics statement that draws a circle, an arc or an ellipse

  CIRCLE [STEP] (x!,y!), radius! [,[color%] [,[start!] [,[end!]
         [,aspect!]]]]

  (x!,y!)    the center (STEP: relative to the last point drawn)
  radius!    the radius in pixels
  color%     the colour (default: the foreground colour)
  start!, end!  the angles, in radians, where an arc starts and ends
  aspect!    the ratio of height to width; draws an ellipse

  Works in the graphics modes of {SCREEN} (1, 2, 13).

.ex
SCREEN 13
CIRCLE (160, 100), 50, 14
CIRCLE (160, 100), 80, 12, , , .5
CIRCLE (160, 100), 30, 10, 0, 3.14159
.endex

  See also: {LINE}  {PAINT}  {PSET}  {SCREEN}

.topic CLS
  CLS - a statement that clears the screen

  CLS

  Clears the screen with the background colour and moves the cursor to the
  top left corner. In graphics modes the last point is the center of the
  screen.

.ex
COLOR 15, 1
CLS
PRINT "White on blue"
.endex

  See also: {COLOR}  {LOCATE}  {SCREEN}

.topic COLOR
  COLOR - a statement that sets the screen colours

  SCREEN 0 (text):    COLOR [foreground%] [,[background%] [,border%]]
  SCREEN 1:           COLOR [background%] [,palette%]
  SCREEN 2 and 13:    COLOR [foreground%]

  Text mode colours:  0 black     4 red        8 gray        12 light red
                      1 blue      5 magenta    9 light blue  13 pink
                      2 green     6 brown     10 light green 14 yellow
                      3 cyan      7 white     11 light cyan  15 bright white
  In text mode, foreground 16-31 blinks; the background is 0-7.
  SCREEN 13 has 256 colours (0-255), set with {PALETTE}.

  The new colours apply to the text printed afterwards; use {CLS} to clear
  the whole screen with the background colour.

.ex
COLOR 14, 1: CLS
PRINT "Yellow on blue"
COLOR 7, 0
.endex

  See also: {SCREEN}  {PALETTE}  {CLS}

.topic CONST
  CONST - a statement that declares a symbolic constant

  CONST name = expression [, name = expression] ...

  A constant is a name for a value that does not change. Use it instead of
  numbers scattered through the program; the program is easier to read and
  to change.

.ex
CONST PI = 3.141593, MAXSCORE = 100
PRINT "Area:"; PI * 2 ^ 2
.endex

  See also: {DIM}  {LET}  {Variables}

.topic COS
  COS - a math function that returns the cosine of an angle

  COS(angle)

  The angle is in radians. To convert degrees to radians, multiply by
  PI / 180 (PI = 3.141593).

.ex
PI = 4 * ATN(1)
PRINT COS(0), COS(PI), COS(60 * PI / 180)
.endex

  See also: {SIN}  {TAN}  {ATN}

.topic CSRLIN
  CSRLIN - a screen function that returns the cursor's row

  CSRLIN

  Returns the row (1-25) of the cursor. {POS}(0) returns its column.

.ex
PRINT "Hello";
R = CSRLIN: C = POS(0)
LOCATE 20, 1: PRINT "The cursor was at"; R; C
.endex

  See also: {POS}  {LOCATE}

.topic DATA,READ,RESTORE
  DATA, READ, RESTORE - statements that keep data in the program

  DATA constant [,constant] ...
  READ variablelist
  RESTORE [line]

  DATA lists numbers and strings (strings containing commas or spaces
  at the ends need quotation marks). DATA statements are not executed.
  READ assigns the next DATA items to the variables, in order through
  the program. RESTORE makes the next READ start with the first DATA
  statement, or with the first one at or after the line label.

  Reading after the last item causes "Out of DATA".

.ex
FOR I = 1 TO 3
  READ Name$, Age
  PRINT Name$; " is"; Age
NEXT
DATA Ada, 36, "Smith, John", 42, Io, 7
.endex

  See also: {DIM}  {Run-Time Errors}

.topic DATE$,TIME$
  DATE$, TIME$ - functions that return the date and the time

  DATE$
  TIME$

  DATE$ returns the date as "mm-dd-yyyy"; TIME$ returns the time as
  "hh:mm:ss". They come from the computer's real-time clock.

.ex
PRINT "Today is "; DATE$; ", the time is "; TIME$
.endex

  See also: {TIMER}

.topic DECLARE
  DECLARE - a statement that declares a SUB or FUNCTION

  DECLARE SUB name [(parameterlist)]
  DECLARE FUNCTION name [(parameterlist)]

  Many programs declare their procedures at the beginning. ARM
  QuickBASIC accepts DECLARE statements and ignores them: you do not need
  them, but programs that have them run unchanged.

  See also: {SUB}  {FUNCTION}  {Differences}

.topic DEF FN,FN
  DEF FN - a statement that defines a one-line function

  DEF FNname[(parameterlist)] = expression

  The function's name starts with FN. It can be used in expressions after
  the DEF FN statement has been executed. {FUNCTION} procedures are more
  powerful.

.ex
DEF FNArea (R) = 3.141593 * R * R
PRINT FNArea(2)

.topic DO,LOOP,UNTIL
  DO...LOOP - statements that repeat a block of statements

  DO [WHILE | UNTIL condition]          DO
     [statementblock]                      [statementblock]
  LOOP                                  LOOP [WHILE | UNTIL condition]

  WHILE repeats while the condition is true; UNTIL repeats until it is
  true. With the test at LOOP, the block runs at least once. DO ... LOOP
  without a condition repeats forever; use EXIT DO to leave it.

  PRINT I;: I = I * 2

.endex

.topic IF,THEN,ELSE,ELSEIF,END IF
  IF - statements that execute statements depending on a condition

  IF condition THEN thenpart [ELSE elsepart]

      [statementblock-1]
  [ELSEIF condition2 THEN
      [statementblock-2]] ...
  [ELSE
      [statementblock-n]]
  END IF

  The single-line form fits on one line; its parts are statements

.topic SUB,END SUB,EXIT SUB,CALL,SHARED,STATIC,COMMON
  SUB - a procedure: a named block of statements

  SUB name [(parameterlist)]
      [statementblock]
      [EXIT SUB]
  END SUB

  [CALL] name [argumentlist]        or    CALL name(argumentlist)

  A SUB is called by its name (with CALL, the arguments are enclosed in
  parentheses). Put SUBs after the main program; press F2 to list them.

  New SUB... (Edit menu) asks for the name of a new SUB, then adds "SUB
  name" and "END SUB" at the end of the program and puts the cursor
  between them. Type the statements of the SUB there.

  In ARM QuickBASIC all variables are global: a SUB sees and changes the
  main program's variables. Parameters are passed by value, so changing a
  parameter does not change the caller's variable. SHARED, STATIC and
  COMMON are accepted and ignored. See {Differences}.

.ex
Greet "World", 3
CALL Greet("ARM-DOS", 1)

SUB Greet (Who$, Times)
  FOR I = 1 TO Times
    PRINT "Hello, "; Who$
  NEXT
END SUB
.endex

  See also: {FUNCTION}  {DECLARE}  {GOSUB}  {View Menu}

.topic SYSTEM
  SYSTEM - a statement that ends the program and leaves BASIC

  SYSTEM

  Like END, but when QB was started with /RUN, SYSTEM returns to ARM-DOS
  instead of to the editor.

  See also: {END}  {Command Line}

.topic TIMER
  TIMER - a function that returns the seconds since midnight

  TIMER

.topic VAL
  VAL - a function that converts a string to a number

.topic OPEN,OUTPUT,APPEND,AS
  OPEN - a statement that opens a file

  OPEN file$ FOR mode AS [#]filenumber

  mode    INPUT    reads the file (it must exist)
          OUTPUT   creates the file (an old file is replaced)
          APPEND   adds to the end of the file (created if missing)

  filenumber is 1-255; use it with PRINT #, WRITE #, INPUT #, LINE INPUT
  #, EOF and CLOSE. Files are text files. File names relative to no
  directory are in the current directory ({Options Menu}, Help Path).

.ex
OPEN "SCORES.TXT" FOR OUTPUT AS #1
PRINT #1, "Ada"; ","; 99
CLOSE #1
OPEN "SCORES.TXT" FOR INPUT AS #1
DO UNTIL EOF(1)
  LINE INPUT #1, L$: PRINT L$
LOOP
CLOSE #1
.endex

  See also: {CLOSE}  {PRINT #}  {INPUT #}  {EOF}  {KILL}  {FILES}

.topic CLOSE
  CLOSE - a statement that closes files

  CLOSE [[#]filenumber [, [#]filenumber] ...]

  Closes the files; CLOSE without numbers closes all open files. END also
  closes all files. Close a file you wrote before opening it again.

  See also: {OPEN}

.topic PRINT #
  PRINT # - a statement that writes data to a file

  PRINT #filenumber, [USING formatstring$;] expressionlist [; | ,]

  Works like {PRINT}, but writes into a file opened FOR OUTPUT or APPEND.
  To write values that INPUT # can read back, separate them with "," or
  use {WRITE} #.

.ex
OPEN "LOG.TXT" FOR APPEND AS #1
PRINT #1, DATE$; " "; TIME$
CLOSE #1
.endex

  See also: {OPEN}  {WRITE}  {INPUT #}

.topic WRITE,WRITE #
  WRITE - a statement that writes data separated by commas

  WRITE [#filenumber,] expressionlist

  Writes the values separated by commas, with strings in quotation marks,
  then a new line. INPUT # reads such lines back into variables.

.ex
OPEN "DATA.TXT" FOR OUTPUT AS #1
WRITE #1, "Smith, John", 42
CLOSE #1
.endex

  See also: {PRINT #}  {INPUT #}  {OPEN}

.topic INPUT #
  INPUT # - a statement that reads data from a file

  INPUT #filenumber, variablelist

  Reads values separated by commas (or line ends) from a file opened FOR
  INPUT. Use {LINE INPUT} # to read whole lines, and {EOF} to test for the
  end of the file ("Input past end of file").

.ex
OPEN "DATA.TXT" FOR INPUT AS #1
INPUT #1, N$, Age
PRINT N$, Age
CLOSE #1
.endex

  See also: {OPEN}  {EOF}  {WRITE}

.topic EOF
  EOF - a file function that tests for the end of a file

  EOF(filenumber)

  Returns true (-1) when the end of a file opened FOR INPUT has been
  reached, otherwise false (0).

.ex
OPEN "README.TXT" FOR INPUT AS #1

  LINE INPUT #1, L$: PRINT L$
WEND
CLOSE #1
.endex

  See also: {OPEN}  {INPUT #}  {LINE INPUT}

.topic ON,ON GOTO,ON GOSUB
  ON...GOTO, ON...GOSUB - jump to one of several lines

  ON expression GOTO | GOSUB line [, line] ...

  The expression is rounded; if it is 1, the program jumps to the first
  line, if 2 to the second, and so on. If it is 0 or greater than the
  number of lines, the program continues with the next statement.
  For error handling, see {ON ERROR}.

.ex
INPUT "Choice (1-3)"; C
ON C GOSUB One, Two, Three
END
One: PRINT "one": RETURN
Two: PRINT "two": RETURN
Three: PRINT "three": RETURN
.endex

  See also: {GOSUB}  {GOTO}  {SELECT CASE}

.topic ON ERROR,RESUME,ERR,ERL,ERROR
  ON ERROR - a statement that handles run-time errors

  ON ERROR GOTO line
  RESUME [NEXT | line]

  After ON ERROR GOTO, a run-time error jumps to the line instead of
  stopping the program. There, ERR is the error number and ERL the line
  number. RESUME retries the statement, RESUME NEXT continues after it.
  ON ERROR GOTO 0 turns error handling off.

.ex
ON ERROR GOTO Oops
OPEN "NOFILE.TXT" FOR INPUT AS #1
PRINT "Opened"
END
Oops:
  PRINT "Error"; ERR
  RESUME NEXT
.endex

  See also: {Run-Time Errors}  {ON}
