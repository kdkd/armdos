ANSI ART
════════

ANSI.ART is a picture made of text characters and ANSI escape sequences
(colours, cursor movement). To see it, the ANSI.SYS console driver must be
loaded: add this line to C:\CONFIG.SYS and restart the computer

    DEVICE=C:\DOS\ANSI.SYS

then type

    TYPE \ANSI\ANSI.ART

Without ANSI.SYS you will see the escape sequences as text.
