COMMANDER KEEN in "KEEN DREAMS" for the ARM PC                   README.TXT
===========================================================================

WHAT IS HERE

  KEEN.EXE     the Keen Dreams game engine for ARM-DOS
  GETKEEN.BAT  fetches the game (see below) and starts it
  GETKEEN.SCR  the TERM script GETKEEN.BAT runs
  README.TXT   this file

  Keen Dreams was made by id Software for Softdisk's Gamer's Edge in 1991.
  In 2014 its source code was released under the GNU General Public
  License (version 2 or later); KEEN.EXE is built from that source (by way
  of the ReflectionHLE port) with the PC parts rewritten for the ARM PC:
  the EGA graphics are drawn in the VGA's 256-colour mode, the PC speaker
  and AdLib sound, the keyboard and the timer are programmed directly, as
  KDREAMS.EXE did on an IBM PC. The source code is on the ARM-DOS disks'
  home page (apps/keen), as the GPL requires.

  The game itself - graphics, levels, sounds, texts - is NOT on this disk.
  It is shareware, (C) 1991-92 Softdisk Publishing.

GETTING THE GAME

  Type GETKEEN. TERM calls The ARM Pit BBS (555-1989) at 14400 bps, logs
  on as a guest, and downloads KEENDRMS.ZIP - the unmodified shareware
  release v1.13 of September 1992 (358,438 bytes). Softdisk's LICENSE.DOC,
  inside the zip, lets BBS SysOps distribute that file as long as nothing
  is added to it or removed from it. UNZIP unpacks it here and the game
  starts. KEENDRMS.ZIP stays in C:\GAMES\KEEN: if you pass the game on,
  pass on the whole zip.

  Already have KEENDRMS.ZIP?  Copy it here and type GETKEEN (or UNZIP -o
  KEENDRMS.ZIP and KEEN).

PLAYING

  Type KEEN in C:\GAMES\KEEN. Arrows move, Ctrl jumps, Alt throws
  flower power, Space shows the status window, F1 help, Esc the menu.
  The shareware texts mention START.EXE and the Gamer's Edge shell: those
  are programs for an Intel PC; on the ARM PC type KEEN.

  KEEN.EXE only runs with the unmodified files of the shareware v1.13.
